Project Title: Lost and Found with AI Prepared By: Akshata Vakurde
Project Guide: Vaishali Mam Department: Information Technology
Purpose & Goals

Purpose: Lost and Found with AI is a web-based platform designed to help users report lost and found items and identify possible matches using item descriptions, images and location information.

Goals:
  • Secure user registration and login
  • Report lost items
  • Report found items
  • Store item information in database
  • AI-based item matching
  • Compare item descriptions and images
  • Use location information for matching
  • Display possible matches
  • Provide match confidence information
  • Send match notifications
  • Allow users to submit claims
  • Accept or reject claims
  • Communication after approval
  • User dashboard and reports
